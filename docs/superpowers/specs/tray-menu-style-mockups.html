交互契约（实现时照此映射）：
① 启停合一：点击 → 进入过渡态（琥珀点「正在启动/停止…」、三控件全禁用、按钮显 spinner）→ 约 1s 后到达目标态。过渡期间重复点击无效（防抖）。
② 重启：仅运行态可用；点击图标自转 + 同款过渡态「正在重启…」→ 回到运行态。
③ 模式切换：即时切换选中态；运行中切换时状态头副标题同步（是否热切换由功能会话定，原型按热切换演示）。
④ AI 加速开关：关 → provider 图标行与 endpoint 区整体降透明并锁交互；开 → 恢复。
⑤ provider 图标：点亮 = 平台检测到使用（检测驱动，不可手动点）；点击查看该 provider 检测详情（toast 演示）。
⑥ endpoint 组：组头点击展开/收起（chevron 旋转 + max-height 动画）；列表项单选即激活（勾移动 + 组头 g-current 淡入更新）；冷却项不可选。
⑦ agent 卡片：点击展开 24h 会话明细（活跃绿点/空闲灰点 + 标题 + 来源 + 相对时间），再点收起。
⑧ 底部三键：外部动作（仪表盘 / 设备互访 / 退出），点击给 toast——真实实现里分别是开浏览器 / 开互访页 / 弹退出确认。
