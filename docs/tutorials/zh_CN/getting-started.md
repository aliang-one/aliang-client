## 0. 准备工作

### 需要准备

- ✅ ALiang Gateway 账号
- ✅ 有效的 API 密钥（已预置在您的账户中）
- ❌ 上游代理（可选，大多数用户不需要）

> 💡 **提示**：API 密钥已预置在您的账户中，登录后在快速配置界面可直接选择使用。无需自行从 OpenAI/Anthropic 等平台申请。

## 快速上手（四步走）

完成以下四步，即可开始加速你的 AI 流量：

```
1. 安装证书 → 2. 登录账号 → 3. 快速配置 → 4. 启动代理
```

### 第一步：安装证书

进入应用后，找到 **证书 CA** 区域，点击 **安装到系统**，确认授权。安装完成后状态显示 **"已信任"**。

### 第二步：登录账号

在仪表盘输入邮箱和密码登录。登录成功后即可解锁所有功能。

### 第三步：快速配置

如果你使用的是 **Codex、Claude Code、OpenCode** 等需要手动写入配置的客户端，点击仪表盘的 **快速配置** 按钮，选择对应软件，选择一个 API 密钥，然后复制到对应配置中，点击 **应用文件** 将配置文件写入指定路径（路径必须是完整的路径）。

> 💡 **提示**：如果你要使用 **VS Code** 或 **Cursor** 的官方原生 AI 界面，请优先选择 **深度模式**，而不是依赖常规模式下的手动配置。

### 第四步：启动代理

回到仪表盘，点击 **启动代理** 按钮。

### 如何确认正常工作？

- 仪表盘显示"代理运行中" ✓
- 打开 Cursor/VS Code 等 AI 软件，尝试使用 AI 功能
- 如果 AI 响应正常，说明配置成功

> 💡 **提示**：切换运行模式后，代理会保持停止状态，需要手动点击「启动代理」。

## 1. 初次使用 - 安装与登录

### 首次打开应用

下载并安装 ALiang Gateway 后，首次打开应用时会处于**未登录状态**。

**未登录状态可用的功能：**

- 证书管理（安装、导出、重新生成）
- 语言和外观设置
- 查看帮助文档

**未登录状态不可用的功能：**

- 启动代理
- 快速配置
- 客户配置修改
- 用户中心（余额查看、充值、套餐兑换等）

## 2. 信任证书（未登录状态）

> ⚠️ **重要提示**：证书状态必须为 **"已信任"** 才能正常使用 AI 流量加速功能。

### 为什么需要安装证书？

ALiang Gateway 需要安装本地证书来识别和处理 AI 流量（如 OpenAI、Claude、Cursor、VS Code 等），从而实现智能路由和加速。

**证书安全说明：**

- 证书仅用于识别和加速 AI 流量
- 不会记录或传输你的任何数据
- 证书存储在你的设备上，不会被第三方获取

### 安装证书步骤

1. 在左侧菜单或仪表盘找到 **证书 CA** 相关区域
2. 点击 **安装到系统**
3. 系统会弹出授权提示，确认后开始安装
4. 安装完成后，证书状态会显示为 **"已信任"**

### 证书状态说明


| 状态  | 含义                       |
| --- | ------------------------ |
| 已生成 | 证书已创建，但未安装到系统            |
| 已安装 | 证书已安装到系统                 |
| 已信任 | 证书已安装并被系统信任，可以正常加速 AI 流量 |


### 导出证书（可选）

如果需要在其他设备上使用，可以点击 **导出** 下载 PEM 格式的证书文件。

## 3. 登录流程

> ⚠️ **重要提示**：用户必须 **已登录** 才能使用代理启动、配置修改等功能。

### 登录方式

1. 在仪表盘找到 **账户访问** 区域
2. 输入邮箱和密码
3. 点击 **登录**

### 登录成功后

- 弹窗自动关闭
- 顶部显示账户状态为"已认证会话激活"
- 解锁功能：
  - 代理启动/停止
  - 快速配置
  - 客户配置修改
  - 快捷聊天
  - 账户余额和充值

### 会话保持

登录成功后，会话信息会保存在本地，下次打开应用时会自动恢复登录状态。

## 4. 快速配置 (Quick Setup)

快速配置可以帮助你为常用 AI 软件（如 Codex、OpenCode、Claude Code）一键生成适配的配置文件。

> 💡 **适用范围**：快速配置主要用于需要手动填写 API 地址、代理或密钥的客户端。若你希望直接使用 **VS Code** 或 **Cursor** 的官方原生 AI 界面，请使用 **深度模式**。

### 使用步骤

1. 点击仪表盘的 **快速配置** 按钮
2. 从预设模板列表中选择你要配置的客户端（如 Codex、OpenCode、Claude Code 等）
3. 选择一个已配置的 API 密钥
4. 系统会自动生成配置文件
5. 点击 **应用文件** 将配置写入指定路径

### 配置文件保存位置

**重要：填写目标路径时，请使用完整路径，不要使用 `~` 代替用户目录。**

例如：

- ✅ 正确：`/Users/你的用户名/.config/xxx/config.json`
- ❌ 错误：`~/.config/xxx/config.json`

### 添加自定义软件

如果预设模板中没有你需要的软件：

1. 点击 **+ 添加软件**
2. 填写软件名称和描述
3. 配置相应的配置文件内容
4. 保存即可

## 5. 运行模式选择

### 两种模式对比


| 场景                                              | 推荐模式        |
| ----------------------------------------------- | ----------- |
| 直接使用 Cursor、VS Code 官方原生 AI 界面                  | 深度模式        |
| 让 Codex、Claude Code、OpenCode 等 CLI / 可手动配置客户端接入 | 常规模式 或 深度模式 |
| 希望所有软件的 AI 流量自动接入，无需逐个配置                        | 深度模式        |
| 命令行工具（curl、wget 等）                              | 常规模式        |


### 深度模式（Deep Mode）

深度模式以 **tun 虚拟网卡** 方式工作，可以加速**所有软件**的 AI 流量，包括：

- **Cursor** - AI 代码编辑器
- **VS Code** - 配合 AI 扩展使用
- **Claude Code** - Anthropic 官方 CLI 工具
- **OpenCode** - 开源 AI 编码工具
- **任何使用 AI 服务的应用**

深度模式让这些软件可以直接使用我们的 AI 服务，享受更快的响应速度和稳定的连接。

**特别说明：**

- 支持 **VS Code 官方原生 AI 界面**
- 支持 **Cursor 官方原生 AI 界面**
- 也支持 **Codex、Claude Code、OpenCode** 等 CLI 工具
- 一般无需为每个软件单独填写代理配置

**优点：**

- 无需为每个应用单独配置
- 支持所有软件的 AI 流量加速
- 全局生效，使用简单

**注意事项：**

- Windows 用户首次切换会自动安装必要驱动
- 如果你的 VPN 也使用深度模式类型的连接，两者可能冲突
- 切换前建议将其他 VPN 调整为非深度模式

### 常规模式（Regular Mode）

常规模式以 **HTTP 代理** 方式工作，适合以下场景：

- **命令行工具** - curl、wget、git 等
- **需要手动写入配置的客户端** - 如 Codex、Claude Code、OpenCode 等
- **需要精细控制代理行为的场景**

**特别说明：**

- 使用常规模式时，用户需要在对应软件中**手动完成代理或配置文件设置**
- 常规模式**不支持 VS Code 官方原生 AI 界面**
- 常规模式**不支持 Cursor 官方原生 AI 界面**
- 如果你想直接在 VS Code / Cursor 的官方原生界面里使用 AI，请切换到 **深度模式**

**配置方法：**
在各应用的代理设置或配置文件中填写：

- 代理类型：HTTP 代理 或 SOCKS5
- 地址：`127.0.0.1`
- 端口：`56432`

## 6. 客户代理配置（可选）

> 💡 **提示**：大多数用户不需要配置此项。如果你有自己的代理服务器需要转发，请参考本节。

在 **客户配置** 中，你可以将自己的 VPN 或代理设置为上游代理。

### 功能说明

将 ALiang 作为中间代理，转发流量到你自己的 VPN（SOCKS 或 HTTP）。

### 配置步骤

1. 进入 **设置** → **客户配置**
2. 找到 **客户代理** 区域
3. 启用客户代理
4. 选择代理类型：
  - **SOCKS5** - 如果你的 VPN 提供 SOCKS5 协议
  - **HTTP** - 如果你的 VPN 提供 HTTP 代理
5. 填写服务器地址和端口
  - 格式：`IP:端口`（如 `127.0.0.1:1080`）
  - 端口号必须在 1-65535 之间
6. 点击 **保存配置**

### 应用场景

```
你的设备 → ALiang Gateway (56432) → 你的 VPN (SOCKS/HTTP) → 目标服务器
```

这种方式适合：

- 已有 VPN线路，想通过 ALiang 加速 AI 流量
- 需要对特定域名进行智能路由

## 7. AI 规则配置

AI 规则让你可以自定义哪些 AI 服务商的流量走代理加速。

### 支持的 AI 提供商

- **OpenAI** - ChatGPT、API 调用
- **Anthropic** - Claude
- **VS Code** - VS Code AI 扩展
- 其他支持自定义端点的 AI 服务

### 配置步骤

1. 进入 **设置** → **客户配置**
2. 找到 **AI 规则** 区域
3. 选择要启用的 AI 提供商（可多选）
4. 为每个提供商配置 **包含域名**

### 域名配置示例

支持输入完整 URL 或纯域名：

```
# 可以这样写：
https://api.openai.com/v1
https://chatgpt.com
anthropic.com
claude.ai

# 系统会自动提取域名部分
```

### 关于隐私的说明

**将第三方 API 放入 AI 规则不会泄露隐私。**

原因：

- ALiang 仅根据域名判断是否为 AI 流量
- 不会查看或记录你的请求内容
- ALiang 充当透明代理，只负责路由和加速

## 8. 代理规则配置

代理规则让你可以自定义特定域名的流量走向。

### 功能说明

你可以指定某些域名：

- **走代理转发** - 流量通过你配置的代理服务器
- **直连** - 流量不经过代理，直接连接

### 配置步骤

1. 进入 **设置** → **客户配置**
2. 找到 **代理规则** 区域
3. 每行一条规则，格式为：

```
domain,example.com,proxy
```

1. 规则说明：
  - 第一部分：固定写 `domain`
  - 第二部分：要匹配的域名
  - 第三部分：`proxy`（走代理）或 `direct`（直连）

### 配置示例

```
# 以下域名走代理
domain,openai.com
domain,anthropic.com
domain,github.com

```

## 9. 常见问题

### Q: 点击启动代理后没反应？

**A:**

1. 确认证书状态为"已信任"
2. 确认已登录
3. 查看运行日志中的错误信息

### Q: 深度模式和其他 VPN 冲突怎么办？

**A:** 建议将其他 VPN 切换到http模式，具体需要用户自行去对应的vpn软件中查找vpn的运行模式。如果必须同时使用，AI 流量可能不稳定。

### Q: 为什么常规模式下 VS Code / Cursor 的官方原生 AI 界面不能直接使用？

**A:** 因为常规模式是本地 `HTTP` 代理模式，只适用于能够手动设置代理、API 地址或配置文件的客户端，例如 Codex、Claude Code、OpenCode 等。VS Code / Cursor 的官方原生 AI 界面请使用 **深度模式**。

### Q: 证书显示"未信任"但已安装？

**A:**

1. 尝试重新启动应用
2. 如果仍有问题，点击"重新安装"证书
3. macOS 用户可能需要在系统设置 → 隐私与安全性中手动信任证书

### Q: 配置文件写入失败？

**A:**

1. 检查目标路径是否存在
2. 确保使用**完整绝对路径**，不要使用 `~`
3. 确保对该路径有写入权限
4. 检查磁盘空间是否充足

### Q: AI 流量没有加速效果？

**A:**

1. 确认 AI 规则中已添加对应域名
2. 确认代理已启动
3. 检查上游代理（客户代理）配置是否正确
4. 查看运行日志排查问题

### Q: 登出后配置会丢失吗？

**A:** 不会。客户配置保存在服务器端，登出后重新登录会自动恢复。

### Q: 账户余额不足会怎样？

**A:** 如果账户余额不足，代理服务将无法启动。可在用户中心查看余额和充值。
