疑点 1：文件访问授权 AgentFileAccess 放哪？

macOS 隐私目录一次性授权（防远程调用弹窗卡死）。它授权的是整个 Agent 链路，不是用户态 agent 独有。
我的建议：放「状态 › 其他」（和系统设置同级的设备级开关）。若你觉得它跟启动工具绑定更紧，也可以放「用户态 agent」。

疑点 2：自定义环境变量 CustomEnv 放哪？

自定义 env 注入 AI run。注入对象是平台通道的 AI run（含 aliangcode 和外部 CLI）。
我的建议：放「Agent › aliangcode」（跟 LLM 设置同区，都是「AI run 用什么环境」）。也可放「用户态 agent」或「状态 › 其他」。

!
